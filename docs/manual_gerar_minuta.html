1O que a ferramenta faz

O gerar_minuta.py é um pequeno programa que faz em segundos um trabalho que antes era manual. Ele lê os documentos de solicitação dos órgãos, monta os incisos do Art. 2º e preenche a minuta do decreto com os valores e as dotações exportados do SIAFI.

Figura 1. O caminho dos arquivos: o que você fornece, o que a ferramenta faz e o que ela cria.

As duas etapas

1
Conferência. A ferramenta lê todos os documentos Word (.docx) da pasta da minuta. Neles, procura as frases que começam com “do saldo…” ou “do excesso…” e trazem “no valor de R$…”. Junta as frases iguais, escreve o valor por extenso, numera os incisos (a partir do II) e grava tudo numa planilha chamada conferencia.xlsx.
✓
Pausa para você conferir. A ferramenta para e pergunta se pode continuar. É a hora de abrir a planilha e ver se os incisos e os valores estão certos.
2
Geração. Com o arquivo do SIAFI (Minuta0250.TXT), a planilha e o modelo oficial, a ferramenta cria a minuta (minuta 250.docx). Antes, faz duas verificações automáticas: se há fontes de recursos especiais e se a conta fecha (o total suplementado deve ser igual à anulação somada aos incisos).

O que ela faz sozinha e o que continua com você

A ferramenta preenche

  • O valor do crédito na ementa e no Art. 1º, em número e por extenso.
  • O Art. 2º: o inciso I (anulação) e os incisos de saldo e excesso.
  • O número do registro no SIAFI.
  • O Anexo, com as dotações de suplementação e de anulação e os totais.
  • Os acentos de palavras comuns nos nomes dos órgãos (ex.: EDUCACAO → EDUCAÇÃO).

Continua com você

  • Colocar na pasta os arquivos certos.
  • Conferir a planilha de incisos.
  • Decidir o que fazer quando aparecer um aviso.
  • Revisar a minuta no Word antes de enviar.
  • Número do decreto, datas e fecho, que ficam como estão no modelo.
Para saber

A ferramenta só lê os documentos dos órgãos, o TXT e o modelo, e nunca altera esses arquivos. Ela só cria (ou substitui) dois arquivos dentro da pasta da minuta: conferencia.xlsx e minuta NNN.docx.

2Preparando o computador

Faça isto uma única vez em cada computador. Leva uns 10 minutos. Se o seu computador já roda a ferramenta, pule para a seção 3.

2.1 Abrir o Prompt de Comando

Vários passos deste manual usam o Prompt de Comando, uma janela preta onde você digita instruções. Para abri-lo:

  1. Aperte a tecla ⊞ Windows do teclado.
  2. Digite cmd.
  3. Aperte Enter. Uma janela preta vai abrir.

Para usar um comando: digite o texto exatamente como está no quadro (ou copie e cole) e aperte Enter.

2.2 Verificar se o Python já está instalado

O Python é o “motor” que faz a ferramenta funcionar. Muitos computadores já têm. No Prompt de Comando:

Digite
python --version

Apareceu um número de versão

Por exemplo, Python 3.13.2. Qualquer versão a partir da 3.9 serve. O Python já está instalado: pule para o item 2.4.

Apareceu um erro ou abriu a Microsoft Store

Por exemplo, “'python' não é reconhecido como um comando interno…”. Feche a Store, se ela abrir, e siga o item 2.3.

2.3 Instalar o Python se precisar

  1. No navegador, acesse python.org/downloads/windows e baixe o instalador para Windows (“Windows installer (64-bit)”) de uma versão 3 recente.
  2. Abra o arquivo baixado. Vai aparecer uma tela parecida com esta:
Python 3.13 (64-bit) Setup✕
Install Python 3.13 (64-bit)
Select Install Now to install Python with default settings, or choose Customize to enable or disable features.

  1. Marque a caixa “Add python.exe to PATH”, no rodapé da tela.
  2. Se você não tem permissão de administrador no computador, desmarque “Use admin privileges when installing py.exe”.
  3. Clique em Install Now e aguarde. No final, clique em Close.
  4. Feche o Prompt de Comando, abra de novo (item 2.1) e repita o python --version. Agora deve aparecer o número da versão.
Atenção

A caixa “Add python.exe to PATH” é o detalhe mais importante. Sem ela, o Windows não encontra o Python e os comandos deste manual dão erro. Se esqueceu, rode o instalador de novo e escolha Modify ou Uninstall, e depois instale outra vez.

Se o computador bloquear a instalação

Peça ao suporte de TI para instalar o Python 3 (versão 3.9 ou mais nova) com a opção “Add python.exe to PATH” marcada.

2.4 Instalar os complementos

A ferramenta usa três complementos gratuitos do Python, chamados de bibliotecas: um que lê e escreve arquivos do Word, outro para o Excel e outro que escreve valores por extenso. Para instalar os três de uma vez, no Prompt de Comando:

Digite
python -m pip install python-docx openpyxl num2words

Vão aparecer várias linhas enquanto ele baixa e instala. Aguarde até a janela voltar a mostrar o cursor. Deu certo se uma das últimas linhas começar com Successfully installed, ou com Requirement already satisfied se os complementos já estavam instalados. Avisos com a palavra WARNING podem ser ignorados.

Para ter certeza de que está tudo pronto, faça este teste:

Digite
python -c "import docx, openpyxl, num2words; print('Tudo pronto!')"
Prompt de Comando—☐✕
C:\Users\seu_usuario>python -c "import docx, openpyxl, num2words; print('Tudo pronto!')"
Tudo pronto!
Atenção
  • O nome do complemento do Word é python-docx, e não só docx. O pacote chamado docx é outro e não funciona.
  • Se aparecer erro de conexão (connection, proxy, SSL), a rede bloqueou o download. Peça ajuda ao suporte de TI.

2.5 Ter o arquivo gerar_minuta.py

A ferramenta é um único arquivo: gerar_minuta.py. Salve-o numa pasta fácil de achar. O lugar onde ele fica não faz diferença para o funcionamento, porque a ferramenta sempre procura as minutas na pasta do OneDrive (item 2.6).

Use sempre a versão mais recente

A versão oficial fica no repositório splor-mg/minuta-decreto do GitHub. Versões antigas espalhadas em pastas podem não ter as correções e verificações descritas neste manual. Na dúvida, peça o arquivo atualizado ao responsável pela ferramenta.

2.6 Conferir a pasta do OneDrive

A ferramenta procura os arquivos sempre neste endereço:

C:\Users\seu_usuario\OneDrive - CAMG\General\@dcmefo\2026\Decretos

Abra o Explorador de Arquivos e confira se você consegue chegar até ela e se, lá dentro, existem:

  • a pasta Minutas Finalizadas;
  • o modelo Manual decreto\minutas padrão\minuta xxx.docx.

Se a pasta @dcmefo não aparecer dentro de OneDrive - CAMG\General, a biblioteca da equipe ainda não está sincronizada no seu OneDrive. Peça ajuda a um colega ou ao suporte.

Pronto para usar quando…
  • python --version mostra a versão 3.9 ou mais nova;
  • o teste mostra Tudo pronto!;
  • você sabe onde está o arquivo gerar_minuta.py;
  • você consegue abrir a pasta Decretos no OneDrive.

3Organizando a pasta da minuta

Cada minuta tem a sua própria pasta dentro de Minutas Finalizadas, separada por mês. A ferramenta trabalha com tudo o que estiver nessa pasta, por isso organizá-la bem é metade do caminho.

Onde fica cada coisa

Decretos ├── Manual decreto │ └── minutas padrão │ └── minuta xxx.docx ← modelo oficial (não mexer) └── Minutas Finalizadas └── 10 outubro ← pasta do mês └── minuta 250 ← pasta desta minuta (você informa esta)

O que tem dentro da pasta da minuta

…\Minutas Finalizadas\10 outubro\minuta 250
W1261 SEE 0000200.docxvocê colocaDocumento do órgão, com os incisos. Lido na Etapa 1.
W1401 CBMMG 0000080.docxvocê colocaOutro documento de órgão. Lido na Etapa 1.
TXTMinuta0250.TXTvocê colocaExportado do SIAFI. Lido na Etapa 2.
Xconferencia.xlsxferramenta criaPlanilha com os incisos (Etapa 1).
Wminuta 250.docxferramenta criaA minuta pronta para revisão (Etapa 2).

Antes de rodar, a pasta precisa ter

1
Os documentos Word (.docx) dos órgãos com os textos dos incisos de saldo e de excesso. Se a minuta não tiver nenhum inciso desse tipo, ainda assim precisa haver pelo menos um .docx na pasta.
2
O arquivo TXT exportado do SIAFI, com o nome começando por Minuta (ex.: Minuta0250.TXT). O número no nome vira o nome da minuta gerada: Minuta0250.TXT gera minuta 250.docx. Deixe só um TXT na pasta.

Como escrever os incisos para a ferramenta encontrar

Nos documentos dos órgãos, a ferramenta só reconhece os incisos escritos no padrão abaixo. Os trechos marcados são os que ela procura:

II - do saldo financeiro da fonte 60 - Recursos Diretamente Arrecadados da Secretaria de Estado de Educação no valor de R$ 50.000,00 (cinquenta mil reais);

  • O trecho começa com “do saldo” ou “do excesso”. A ferramenta copia daí até antes de “no valor de”. O que vem antes (como “II -”) é ignorado e renumerado.
  • Tem a expressão “no valor de”, seguida do valor em reais com centavos: R$ 50.000,00. Um valor escrito como R$ 50.000, sem os centavos, não é encontrado.
  • A frase inteira fica no mesmo parágrafo, sem Enter nem quebra de linha no meio.
  • Maiúsculas e minúsculas não fazem diferença.

Se dois documentos tiverem exatamente a mesma descrição (desconsiderando maiúsculas e espaços a mais), a ferramenta soma os valores num inciso só. É isso que a tela chama de consolidação.

Importante: deixe a pasta “limpa”

Todo arquivo .docx da pasta é lido na Etapa 1, inclusive uma minuta gerada antes, e ela contém os mesmos incisos. Por isso:

  • Se for rodar a ferramenta de novo, mova ou apague a minuta NNN.docx antiga antes. Se ela ficar na pasta, os incisos são contados em dobro (veja a seção 5.2).
  • Não deixe na pasta versões antigas ou cópias dos documentos dos órgãos.
  • Os arquivos temporários do Word, que começam com ~$, são ignorados. Não se preocupe com eles.

4Usando a ferramenta, passo a passo

Com o computador preparado (seção 2) e a pasta organizada (seção 3), siga os sete passos abaixo. No dia a dia, o processo todo leva poucos minutos.

1

Abrir a ferramenta

Há dois jeitos. Os dois fazem a mesma coisa.

Jeito A: dois cliques (mais simples)

Dê dois cliques no arquivo gerar_minuta.py. Uma janela preta vai abrir.

Se o arquivo abrir num editor de texto em vez de rodar, clique nele com o botão direito → Abrir com → Python.

Jeito B: pelo Prompt (melhor quando dá erro)

  1. Abra a pasta onde está o gerar_minuta.py.
  2. Clique na barra de endereço do Explorador, apague o que estiver escrito, digite cmd e aperte Enter.
  3. Na janela preta, digite python gerar_minuta.py e aperte Enter.
Dica

No Jeito A, a janela fecha sozinha 5 segundos depois de terminar. Se aparecer um erro, pode não dar tempo de ler. No Jeito B, a janela continua aberta e dá para ler tudo com calma. Use o Jeito B sempre que algo der errado.

2

Informar a pasta da minuta

A ferramenta mostra onde vai procurar e pergunta qual é a pasta da minuta:

gerar_minuta.py—☐✕

============================================================

Informe a subpasta da minuta (ex: 05 maio\minuta 83):
> 10 outubro\minuta 250 2
1A Base é a pasta Minutas Finalizadas no OneDrive. Você não precisa digitar essa parte.
2Digite o mês, uma barra invertida \ e o nome da pasta da minuta, exatamente como aparecem no Explorador (com espaços e acentos). Depois aperte Enter.

Atalho: copiar e colar o caminho
  1. No Explorador, clique com o botão direito na pasta da minuta e escolha Copiar como caminho (ou selecione a pasta e aperte Ctrl+Shift+C).
  2. Na janela preta, cole com Ctrl+V (ou com o botão direito do mouse) e aperte Enter.

O caminho colado vem completo e entre aspas, e a ferramenta entende assim mesmo. Isso evita erros de digitação.

3

Etapa 1: a conferência

Logo depois, a ferramenta lê os documentos e mostra o resultado:

gerar_minuta.py—☐✕

  Etapa 1 — Conferência
------------------------------------------------------------
Processo concluído. 2 incisos lidos, 1 2 após consolidação. 2 Arquivo: …\Minutas Finalizadas\10 outubro\minuta 250\conferencia.xlsx 3

  Conferência concluída. Prosseguir com a geração da minuta? [s/n]: 4
1Incisos lidos: quantas frases de saldo ou excesso a ferramenta encontrou, somando todos os documentos.
2Após consolidação: quantos incisos ficaram depois de juntar as descrições idênticas.
3Onde a planilha conferencia.xlsx foi salva: na própria pasta da minuta.
4A pergunta. Não responda ainda. Primeiro faça o Passo 4.
Os números fazem sentido?

Se você esperava 5 incisos e apareceram 10, provavelmente há uma minuta antiga ou um documento repetido na pasta. Responda n, arrume a pasta (seção 3) e rode de novo.

Se nenhum documento tiver incisos de saldo ou excesso, aparece a mensagem abaixo. Isso é normal quando a minuta só tem anulação. Nesse caso o Art. 2º sai num parágrafo único, sem incisos.

gerar_minuta.py—☐✕
Nenhum inciso de 'do saldo'/'do excesso' com 'no valor de' encontrado.
Arquivo criado vazio (apenas cabeçalho): …\minuta 250\conferencia.xlsx
4

Conferir a planilha conferencia.xlsx

Com a pergunta ainda na tela, abra a pasta da minuta e dê dois cliques em conferencia.xlsx. Ela tem este formato:

conferencia.xlsx · planilha “base”
AB
1incisosvalor
2II - do saldo financeiro da fonte 60 - Recursos Diretamente Arrecadados da Secretaria de Estado de Educação no valor de R$50.000,00 (cinquenta mil reais);50000
3III - do excesso de arrecadação da receita de Taxa de Incêndio do Corpo de Bombeiros Militar do Estado de Minas Gerais no valor de R$25.000,50 (vinte e cinco mil reais e cinquenta centavos);25000,5

Coluna A (incisos): o texto exatamente como vai entrar no Art. 2º da minuta. Coluna B (valor): o valor em número, usado para conferir se a conta fecha.

  • Todos os incisos esperados estão na lista?
  • Os valores estão corretos?
  • O texto e o valor por extenso estão corretos?
  • A numeração segue em sequência (II, III, IV…)?
Precisa corrigir algo?

O melhor é corrigir o documento de origem do órgão, responder n e rodar de novo. Se preferir corrigir direto na planilha:

  • se mudar um valor, mude nas duas colunas: no texto (com o extenso) e no número da coluna B;
  • se apagar uma linha, renumere à mão os incisos seguintes, porque a numeração faz parte do texto;
  • não apague a primeira linha (incisos / valor);
  • salve e feche o Excel antes de voltar para a janela preta.

As correções feitas à mão se perdem se você rodar a ferramenta de novo, porque a planilha é recriada do zero.

5

Responder à pergunta

Volte para a janela preta, digite a resposta e aperte Enter:

A ferramenta segue para a Etapa 2. Também aceita sim.

n: parar aqui

A planilha fica salva e nada mais é criado. Também aceita não.

  Encerrado. A conferência foi gerada; a minuta não foi solicitada.

7

Revisar a minuta no Word

Abra a minuta 250.docx na pasta da minuta. Os trechos destacados abaixo são os que a ferramenta preencheu no exemplo:

Abre crédito suplementar no valor de R$175.000,50

Art. 1º – Fica aberto crédito suplementar no valor de R$175.000,50 (cento e setenta e cinco mil reais e cinquenta centavos) indicado no Anexo, […]

Art. 2º – Para atender ao disposto no art.1º serão utilizados recursos provenientes:

I – da anulação das dotações orçamentárias indicadas no Anexo, no valor de R$100.000,00 (cem mil reais);

II – do saldo financeiro da fonte 60 - Recursos Diretamente Arrecadados da Secretaria de Estado de Educação no valor de R$50.000,00 (cinquenta mil reais);

III – do excesso de arrecadação da receita de Taxa de Incêndio do Corpo de Bombeiros Militar do Estado de Minas Gerais no valor de R$25.000,50 (vinte e cinco mil reais e cinquenta centavos).

[…] Anexo: registro no SIAFI, dotações e totais […]

A ferramenta faz o trabalho pesado, mas a revisão continua sendo sua:

  • Ementa e Art. 1º: o valor e o extenso batem com o total da suplementação?
  • Art. 2º: o inciso I (anulação) e os demais incisos estão certos? O último termina com ponto e os outros com ponto e vírgula?
  • Anexo: o número do registro no SIAFI, os órgãos, as dotações e os totais estão certos?
  • Acentos no Anexo: o SIAFI exporta os nomes sem acento. A ferramenta corrige só palavras comuns (EDUCAÇÃO, SAÚDE, POLÍCIA, FUNDAÇÃO…) e as outras ficam sem acento, como em “ECONOMICO”. Corrija à mão no Word.
  • Número do decreto, datas e fecho: a ferramenta não mexe nesses trechos, que ficam como estão no modelo.
  • Casos especiais (PROPAG, Brumadinho, Mariana, emenda, transposição, lei específica…): a ferramenta usa sempre o modelo padrão minuta xxx.docx. Compare com o modelo específico da pasta minutas padrão e ajuste o texto se necessário.

5Entendendo os avisos

Antes de criar a minuta, a ferramenta faz duas verificações. Se estiver tudo certo, elas passam sem mostrar nada. Se encontrarem algo, aparece um quadro ATENÇÃO perguntando se você quer continuar.

5.1 Fontes de recursos especiais

gerar_minuta.py—☐✕
============================================================
  ATENÇÃO — VERIFICAÇÃO DA MINUTA
============================================================

  ⚠️  Minuta contém Recursos de Brumadinho 1
    → 1401.06182052-4.115-0001-3390-0-95.1                          25.000,00 2

============================================================
  Deseja continuar mesmo assim? [s/n]:
1O tipo de recurso encontrado.
2A dotação do TXT que causou o aviso. Se houver várias, todas aparecem.

Esse aviso aparece quando alguma dotação do TXT usa recursos que têm tratamento especial:

Quando apareceMensagem
Fonte 89, ou IPU 0 (com qualquer fonte)Minuta contém Recursos do PROPAG
Fonte 95Minuta contém Recursos de Brumadinho
Fonte 80Minuta contém Recursos de Mariana

Como achar a fonte e o IPU no código da dotação

1401.06182052-4.115-0001-3390-0-95.1
fonte = 95IPU = 1

São os dois números do final do código, separados por um ponto: primeiro a fonte, depois o IPU.

O que fazer
  • O aviso era esperado (a minuta é mesmo de recursos de Brumadinho, por exemplo): responda s. A minuta é gerada normalmente. Depois, confira a redação com o modelo específico da pasta minutas padrão: minuta (fonte 95).docx, minuta (fonte 80).docx ou minuta (propag).docx.
  • O aviso não era esperado: responda n e verifique as dotações no TXT ou no SIAFI.

5.2 Divergência de valores

A regra é simples: o total suplementado tem que ser igual à soma da anulação com os incisos, centavo por centavo.

SuplementaçãoArt. 1º · do TXTR$ 175.000,50
=
Anulaçãoinciso I · do TXTR$ 100.000,00
+
Incisos II, III…da conferencia.xlsxR$ 75.000,50

Não há margem de tolerância: até R$ 0,01 de diferença já gera o aviso. Exemplo de quando falta dinheiro no Art. 2º:

gerar_minuta.py—☐✕
============================================================
  ATENÇÃO — DIVERGÊNCIA DE VALORES
============================================================

  Valor Suplementado (Art. 1º) : R$ 175.000,50
  Anulação (TXT)               : R$ 99.999,00
  Incisos (conferencia.xlsx)   : R$ 75.000,50

7Perguntas frequentes

Respostas curtas para as dúvidas mais comuns.

Preciso sempre passar pelas duas etapas?

A ferramenta sempre começa pela Etapa 1 (conferência). Depois dela, você escolhe se segue para a geração (s) ou se para (n).

Posso rodar a ferramenta de novo na mesma pasta?

Pode, mas antes mova ou apague a minuta gerada (minuta NNN.docx), senão os incisos são contados em dobro. Lembre também que a conferencia.xlsx é recriada do zero.

A ferramenta altera os documentos dos órgãos ou o TXT?

Não. Ela só lê esses arquivos e só cria (ou substitui) a conferencia.xlsx e a minuta NNN.docx.

Posso corrigir a conferencia.xlsx à mão?

Pode, durante a pausa entre as etapas (Passo 4). Mude as duas colunas, salve e feche o Excel antes de responder s.

O que quer dizer “consolidação”?

Quando dois documentos trazem exatamente a mesma descrição de inciso, a ferramenta junta os dois num inciso só e soma os valores.

Por que os incisos começam no II?

Porque o inciso I do Art. 2º é sempre o da anulação, que vem do TXT. Os incisos de saldo e de excesso vêm em seguida.

E se a minuta não tiver nenhum inciso de saldo ou excesso?

Funciona normalmente. A planilha sai só com o cabeçalho e o Art. 2º é escrito num parágrafo único, só com a anulação.

Onde a minuta é salva? E se já existir uma com o mesmo nome?

Na própria pasta da minuta, com o nome minuta NNN.docx, em que NNN vem do nome do TXT. Se já existir um arquivo com esse nome, ele é substituído sem aviso.

Funciona para minutas de emenda, transposição ou lei específica?

A ferramenta usa sempre o modelo padrão minuta xxx.docx. Para esses casos, compare o resultado com o modelo específico da pasta minutas padrão e ajuste no Word.

Preciso de internet?

Só para instalar o Python e os complementos (seção 2) e para o OneDrive sincronizar os arquivos. A ferramenta em si funciona sem internet.

Posso alterar o modelo minuta xxx.docx?

Evite. A ferramenta depende da posição dos parágrafos e das marcações “xxx” do modelo. Mudanças podem fazer a ferramenta parar de funcionar ou preencher o lugar errado. Se for preciso mudar, combine antes com o suporte técnico.

Quem procuro se nada disso resolver?

O responsável pela ferramenta na equipe. Mande um print da janela preta, de preferência aberta pelo Jeito B, e diga qual minuta você estava gerando.

AApêndice: para quem dá suporte técnico

Informações para quem mantém a ferramenta. Quem só usa no dia a dia não precisa desta parte.

A.1 Onde a ferramenta procura os arquivos

O caminho-raiz é resolvido nesta ordem:

  1. a variável de ambiente MINUTA_BASE, se estiver definida;
  2. senão, o padrão %USERPROFILE%\OneDrive - CAMG\General\@dcmefo\2026\Decretos, definido na constante _DEFAULT_BASE, no início do script.

A partir dele, a ferramenta usa Minutas Finalizadas e o modelo Manual decreto\minutas padrão\minuta xxx.docx.

Virada do ano

O ano 2026 está fixo em _DEFAULT_BASE. Em 2027 é preciso atualizar o script ou definir a variável para cada usuário (vale para as próximas janelas do Prompt):

Digite
setx MINUTA_BASE "%USERPROFILE%\OneDrive - CAMG\General\@dcmefo\2027\Decretos"

A.2 Dependências do modelo minuta xxx.docx

O preenchimento depende da estrutura do modelo. Não altere:

  • a ordem dos primeiros parágrafos: a ementa é o 2º parágrafo; o Art. 1º, o caput do Art. 2º, o inciso I e o marcador “Xxx” dos demais incisos são do 5º ao 8º;
  • os marcadores xxx e xxx por extenso;
  • o parágrafo com “Sob o … xxx” (número do registro no SIAFI);
  • o parágrafo que começa com “SE REFERE O ART.1” e contém “xxx” (título do Anexo).

A.3 Acentuação dos nomes de órgãos

As palavras re-acentuadas nos títulos do Anexo ficam no dicionário WORD_FIXES do script (ex.: "EDUCACAO": "EDUCAÇÃO"). Para acrescentar uma palavra, inclua um novo par sem acento → com acento, em maiúsculas.

A.4 Rodar informando a pasta direto

A pasta da minuta pode ser passada como argumento, sem a pergunta inicial:

Digite
python gerar_minuta.py "10 outubro\minuta 250"

A.5 Limitações conhecidas

  • Releitura da minuta gerada: a Etapa 1 lê todo *.docx da pasta (exceto ~$*), inclusive a minuta NNN.docx de uma execução anterior, o que duplica os incisos. A verificação de balanço detecta o problema. Uma melhoria possível é ignorar minuta *.docx na conferência.
  • TXT sem anulação: sem a linha “TOTAL DA ANULACAO” (ou “TOTAL DA SUPLEMENTACAO”), a Etapa 2 para com 'NoneType' object has no attribute 'replace'.
  • Formato do valor: só é reconhecido o padrão R$ 1.234,56, com vírgula e dois decimais, no mesmo parágrafo de “do saldo” ou “do excesso” e de “no valor de”.
  • Balanço sem tolerância: a comparação é feita em centavos inteiros e qualquer diferença gera o aviso.

A.6 Requisitos

Python 3.9 ou mais novo e os complementos python-docx, openpyxl e num2words, listados em requirements.txt. Para instalar pelo repositório: python -m pip install -r requirements.txt.
